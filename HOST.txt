Murphy Pilot + House — host on your PC from GitHub.

Do not use Google Apps Script /exec. Do not paste Index.html.
The private repo is the site.

  git clone https://github.com/justintmurphy/MurphyPilot.git
  cd MurphyPilot
  ./serve.sh          # Windows: serve.bat

  Pilot  http://127.0.0.1:8765/
  House  http://127.0.0.1:8765/house/

Update: git pull   then refresh the browser.
Do not open file:// if you want the JSON snapshots to load.

Snapshot jobs write JSON into this repo. Gmail is backup only.
